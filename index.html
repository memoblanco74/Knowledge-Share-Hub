MSG to PDF Converter

  1. Download the batch script "Convert-MsgToPdf.ps1" from the button below.
  2. Create a new folder named Knowledge in your C:\ drive.
  3. Place all the email files (.msg) that you want to convert into C:\Knowledge
  4. Right-click on the downloaded batch script and select "Run with PowerShell".
  5. Once the conversion is complete, upload the newly generated PDF files to the system.
